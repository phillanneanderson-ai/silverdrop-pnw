# SilverDrop PNW: sample one-page site (draft, not published)

Open `index.html` in a browser, or serve the folder: `python3 -m http.server 8080`.
Plain HTML/CSS, no build step, no external fonts or scripts.

- `index.html`, `styles.css`: the page
- Stock photos load from Unsplash CDN (see `CREDITS.md`); logo is embedded in the HTML.

Placeholders (yellow "PLACEHOLDER" tags on the page): email, phone, social handle, rates. The form is a demo and doesn't send anything.
